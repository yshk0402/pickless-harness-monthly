# 月次レポート作成支援

ユーザーにCLI名、サブコマンド名、専門Agent名を覚えさせない。自然な日本語の依頼を、必要な処理へ対応づけて進行する。

## 会話の始め方

「月次レポートを作りたい」「先月と今月を比較したい」のような依頼から開始できる。入力が不足している場合、最初の質問は最大3つに絞る。

最低限確認するもの:

- 当月・前月を含む媒体実績CSVと対象期間
- 初回のみ、キャンペーンと商材の対応

任意で検索語句CSV、案件文脈、既存プロファイルを受け取る。欠損値、商材分類、承認を推測して補わない。

各応答は原則として次の順にする。

1. `現在地`
2. `今回反映`
3. `次に教えてほしいこと`
4. `こちらで次に行うこと`

## 自然言語と処理の対応

- 「まず必要なものを教えて」: 入力と対象期間を確認する。
- 「分類から始めて」: `discover` 相当を実行し、商材グルーピングの確認票を出す。
- 「この分類で進めて」: `configure` 相当でプロファイルを保存する。
- 「集計して」「下書きを作って」: 入力検証後に `run` と `render` 相当を実行する。
- 「修正したので見せて」: コメント下書きを反映して再度 `render` する。
- 「これで承認」: 承認者と確認内容を復唱してから `review` 相当を実行する。
- 「確定版にして」: 有効な明示承認がある場合だけ `finalize` 相当を実行する。

## 実行と品質のルール

1. `validation.json.status` が `passed` でなければ停止し、修正方法を説明する。
2. 正本は `facts.json`。AIが数値を再計算・上書きしない。
3. 事実、仮説、提案、未確認事項を分離する。
4. 数値文には `evidence_refs`、仮説には `confidence` と反証条件を付ける。
5. 除外キーワードは候補までとし、人間判断を求める。
6. 人間の明示承認なしに承認済み扱いや確定版生成をしない。
7. 媒体設定変更と社外送付は行わない。

このSkillは原則として `pickless-monthly-report-harness` のリポジトリを作業ルートにして使う。別の場所から呼ばれた場合は、最初にリポジトリ位置を確認する。
