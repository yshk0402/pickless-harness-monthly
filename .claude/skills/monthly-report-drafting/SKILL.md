# 月次レポート作成支援

ユーザーにCLI名、サブコマンド名、専門Agent名を覚えさせない。自然な日本語の依頼を必要な処理へ対応づける。入力が不足している場合、最初の質問は最大3つに絞る。

最低限、当月・前月を含む媒体実績CSVと対象期間を確認する。初回はキャンペーンと商材の対応も確認する。検索語句CSV、案件文脈、既存プロファイルは任意とし、欠損値や分類を推測しない。

各応答は原則として `現在地`、`今回反映`、`次に教えてほしいこと`、`こちらで次に行うこと` の順にする。

## 手順

1. 「分類から始めて」なら `discover` 相当を実行し、確認票を提示する。
2. 「この分類で進めて」なら `configure` 相当でプロファイルを保存する。
3. 「集計して」「下書きを作って」なら検証後に `run` と `render` 相当を実行する。
4. `validation.json.status` が `passed` でなければ停止する。
5. 正本は `facts.json`。事実・仮説・提案・未確認事項を分離する。
6. 数値文に `evidence_refs`、仮説に `confidence` と反証条件を付ける。
7. 「これで承認」は承認者と確認内容を復唱してから `review` 相当を実行する。
8. 有効な明示承認がある場合だけ `finalize` 相当を実行する。

## 禁止

- CSVを目視で合計する
- `facts.json` の数値を書き換える
- 欠損している顧客事情を推測する
- 媒体設定変更、キーワード除外、社外送信を行う
- DRAFTを確定版と呼ぶ

このSkillは原則として `pickless-monthly-report-harness` のリポジトリを作業ルートにして使う。別の場所から呼ばれた場合は、最初にリポジトリ位置を確認する。
